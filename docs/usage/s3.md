# `dalmatian s3`

Commands for inspecting S3 bucket properties and deleting buckets.

---

## `dalmatian s3 list-bucket-properties`

**Safety:** Read-only

Inspects ACL ownership/full-control grants and other properties for a specific S3 bucket or all buckets in an account.

### Syntax

```bash
dalmatian s3 list-bucket-properties -i <infrastructure> -e <environment> [-b <bucket_name>] [-h]
```

### Required options

- `-i <infrastructure>` — Infrastructure name.
- `-e <environment>` — Environment name.

### Optional options

- `-b <bucket_name>` — Target bucket name (defaults to all buckets in the resolved account).
- `-h` — Show help.

### Exit states

- `0` — Bucket properties printed.
- Non-zero — Missing `-i`/`-e`, `-h`, or S3 API failure.

---

## `dalmatian s3 empty-and-delete-bucket`

**Safety:** Destructive

Recursively deletes all objects, all object versions (in batches of 500), and delete markers from an S3 bucket, then deletes the bucket itself.

### Syntax

```bash
dalmatian s3 empty-and-delete-bucket -i <infrastructure> -e <environment> -b <bucket_name> [-h]
```

### Required options

- `-i <infrastructure>` — Infrastructure name.
- `-e <environment>` — Environment name.
- `-b <bucket_name>` — Bucket name to empty and delete.

### Safety notes

- **Irreversible:** Permanently deletes all objects and version history in the bucket after a single confirmation prompt. **The prompt defaults to yes**: pressing Enter deletes the bucket.
- Note: Always pass `-b <bucket_name>` explicitly (even though `-h` marks it optional, the implementation requires a bucket name).

### Exit states

- `0` — Bucket emptied and deleted, or confirmation prompt declined.
- Non-zero — Missing `-i`/`-e`, `-h`, or S3 API failure.
